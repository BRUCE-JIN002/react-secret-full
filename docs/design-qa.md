# 网站重构验收

验收日期：2026-09-06。参考：https://message163.github.io/react-docs/ 。本地生产预览：http://127.0.0.1:4173/ 。

## 设计目标与结果

通过本次站点框架验收。参考站的首页、导航与文档阅读结构已用于真实 VitePress 网站；保留 React Secret 名称、现有 React 品牌资源和项目内容，并未复制参考站作者信息或课程。

浏览器中将参考站与新版首页截图放在同一轮输出中比较：桌面保留顶部导航、左右分栏首屏、紫色主按钮和四列内容入口；手机保留居中首屏、折叠菜单和单列内容卡片。新版卡片额外提供分类入口，正文比参考站更长，因此卡片高度不同。文档页采用左侧分类、中央正文、右侧目录，手机折叠导航。截图证据见本次任务的桌面及移动端对照工具输出。

## 验证范围

- `npm run build`：通过文档同步检查、旧导航 64 项覆盖检查、TypeScript 检查、React 演示构建和 VitePress 静态渲染。
- `npm run check-site`：69 篇业务文档、首页、指南、引用资源、演示入口、站点地图、404 页面及 GitHub Pages 标记通过。
- 生产预览中文搜索“日历”：同时找到 Calendar 与 MinCalendar；方向键和 Enter 可跳转。
- 文档深链接刷新后仍可阅读，并可点击“运行演示”加载打包后的 React iframe。
- 迷你日历选择 9 月 8 日后显示对应选择结果；重置后恢复当天初始状态。
- 明暗主题切换、刷新后主题保留；手机主导航可展开和关闭。
- 390px 手机宽度下文档总宽度为 390px，无页面横向溢出；日历实例纵向排列，演示区域可滚动。
- 检查过的生产首页、文档和日历演示未捕获浏览器 error 日志。

## 已修正的问题

1. 首页中文标题自动换行割裂句子：增加明确换行。
2. 默认英文分词无法充分匹配“迷你日历”：搜索索引与查询使用中文分词。
3. 文档中裸 localhost 示例 URL 被识别为死链接：改为代码文字。
4. 静态输出目录指向仓库外：统一为仓库内 `build/`。
5. 桌面文档中的双日历宽度过大：调整演示容器宽度，保持并排布局。

## 验收边界

本轮验证网站框架与代表性交互，未逐一重测所有历史演示的业务逻辑。原有 useEventListener 的两项已知测试失败仍记录在 README；本轮未修改该 Hook。部分历史示例依赖上传服务、浏览器权限或第三方资源，使用边界写在各自文档中。新版已于 2026-09-06 发布到 https://bruce-jin002.github.io/ ，生产首页与本地构建 SHA-256 一致，线上文档深链接刷新和 React 日历演示加载通过。
