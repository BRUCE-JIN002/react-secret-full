# 从这里开始

**React Secret** 是一个围绕 React 的学习与实践网站。在这里，你可以阅读实现思路，尝试组件交互，再回到源码理解每一步。

## 你可以找到什么

| 内容 | 适合做什么 |
| --- | --- |
| [自定义 Hooks](/hooks/) | 学习状态管理、副作用、浏览器交互和性能优化 |
| [组件实践](/components/) | 探索日历、表单、浮层、上传和其他可复用组件 |
| [生态探索](/ecosystem/) | 上手 react-spring、react-dnd、React Flow 和状态管理 |
| [综合项目](/projects/) | 在一个完整功能中组合组件、交互与持久化状态 |

## 建议的阅读顺序

如果刚开始接触这个项目，可以从简单的状态逻辑入手，再逐步过渡到组件和项目：

1. [useCounter 计数器](/hooks/useCounter)：理解一个 Hook 如何封装状态与操作。
2. [MinCalendar 迷你日历](/components/min-calendar)：体验日期选择、回调和实例方法。
3. [Form 表单](/components/form)：学习字段收集、上下文与校验。
4. [TodoList 待办项目](/projects/todolist)：组合拖拽、状态管理和持久化。

## 阅读文档与运行演示

文档按功能组织，右侧目录可以快速定位 API 和使用边界。使用顶部搜索，也可以直接查找内容中的关键词。

带有在线示例的页面提供「运行演示」入口。示例按需加载，你可以在页面内体验，也可以通过「独立窗口」打开更宽的画布。重置演示会重新加载页面，但不会删除 TodoList 等示例保存在浏览器中的数据。

Hooks 页面均提供文档与实现源码；只有已实现独立示例的 Hook 才展示运行入口。

::: tip 阅读与动手结合
先看基本用法，尝试不同输入，再阅读 API 和使用边界。源码是理解这个项目行为的最终依据。
:::

## 使用前需要了解

项目示例用于学习和实验。表单不会进行真实登录，上传需要本地服务；图片、部分图标与 Monaco 编辑器需要网络。各页面的「使用边界」列出了具体说明。

准备修改源码时，继续阅读[本地开发](/guide/development)。
